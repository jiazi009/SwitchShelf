# Backend local preparation (worker)

Implemented a metadata-only local plan check in `SwitchShelfBackend/Preflight` and integrated it into the existing SwiftUI queue. The app builds offers only from included plan content IDs uniquely mapped to current snapshot `LocalContent` URLs; it does not interpret opaque plan IDs as paths. The check rejects absent/offline/unreadable/symlink/non-regular/size-changed sources, mismatched plan/snapshot names and sizes, duplicate IDs or exact wire names, invalid or oversized UTF-8 names, and lists exceeding 65,536 UTF-8 bytes (`basename + LF` per pinned host protocol). Unicode Chinese basenames remain valid; colon, C1 controls and Unicode line separators now follow the Protocol name predicate exactly, empty IDs are rejected, and duplicate wire names compare exact UTF-8 bytes. The UI does not expose opaque source IDs in issue text. Disk metadata runs on a backend actor, outside MainActor; no body reads, hashes, copies, USB opens, uploads, or original-file mutations occur.

The queue retains its JSON model and editable order, inclusion, notes, and local SD/NAND intention. A preparation result becomes stale when the ordered plan, included entries, target or current snapshot source evidence changes. A file may also change *after* the check without a library refresh; the UI explicitly says checks are point-in-time and must be repeated before any future transfer. The disabled Start action cannot invoke a transfer. USB 057e:3000 is described only as a Backend descriptor candidate; MTP 057e:201d inventory is separate, read-only, and excluded if both candidate modes appear. The Backend protocol does not set or enforce SD/NAND and a successful local check does not verify package identity or device installation.

The BackendPreflight tests use temporary local fixtures only, not SMB or hardware. Existing plan storage and cache implementation are unchanged; no migration is introduced. Hardware behavior, device-side target selection, installation success semantics, and live GUI acceptance remain unverified and out of scope.
