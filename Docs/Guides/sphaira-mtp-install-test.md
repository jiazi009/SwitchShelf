# sphaira 原生 MTP 单文件安装测试（0.3.0）

这是已接入真实 USB 发送的**试验包**，尚未经实机安装验收。启动应用、加入队列或检查计划都不会自动安装。只有你在确认页核对一个具体文件并确认设备端设置后才会发送。

## 手动步骤

1. 保存原有工作，使用数据线连接一台 Switch。完整退出 OpenMTP、Android File Transfer、“预览”等其他 MTP 客户端。不要停止系统服务。
2. sphaira 中启用 MTP、Games 和 Install；**进入 MTP Install 页面**。仅在普通 MTP 模式看到 Install 目录不够。自行核对 sphaira 的安装设置及 SD／机身存储目标，保持该页面。
3. SwitchShelf 的“安装队列”中展开“内容清单”，**整个队列只勾选一个你有权安装的文件**，建议首次选合适的小包。不要假设一项计划只有一个文件。本体、更新、DLC 不能在本次试验中自动批量执行。
4. 点击“检查计划”。这一步只查来源和文件元数据，不读包内容、不连接 USB。检查不通过或计划过期时先处理来源／重新检查。
5. 点击“核对并安装一个文件…”。核对显示的**完整文件路径、字节数和计划目标**；计划目标不能替你设置 sphaira 的实际安装位置。四项确认均由你核实后，点击“确认并发送这一个文件”。
6. 等待进度和设备响应。显示“传输完成，等待设备确认”仍不代表安装成功：请查看 sphaira 的设备端结果。确认辅助进程退出后，可另外读取 Games 清单获取独立证据；本地文件名身份仍只作候选。

## 中断与错误

- “取消传输”会停止独立辅助进程，并等待验证退出。**不保证设备端回滚**；不要在不知道 sphaira 状态时重复安装。
- 会话占用／权限错误：完整退出其他客户端，查看 sphaira 屏幕，必要时手动重连。软件不会杀系统相机服务、抢占驱动或自动改走 Backend。
- 设备能力、版本描述或 Install 存储不匹配会拒绝发送，不会改写 microSD、Contents 或其他存储作为替代。
- 默认每次 USB 调用 20 秒超时、无进度 120 秒或总计 2 小时中止。即便所有字节已提交，最终响应缺失时仍是未知。没有自动重试、续传、删除对象或清理安装内容。
- 测试期间不要退出应用、切换 USB 模式或断线；退出／崩溃会让子进程停止，已有部分写入的结果仍需检查设备。无法确认进程退出时会阻止后续发送。

点击“查看本地传输记录”打开：
`~/Library/Application Support/SwitchShelf/MTPInstallAttempts/`

每次确认使用独立目录，保留请求、源文件元数据指纹、最近传输意向／进度、worker 结果和 supervisor 退出结论。不要把 `transferring`、100% 进度或 `transferredAwaitingConfirmation` 解释为已安装。反馈问题时提供错误文字和设备端现象；记录中有本地路径，分享前注意隐私。
