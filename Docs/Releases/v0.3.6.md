# SwitchShelf 0.3.6 · 预发布版 / Pre-release

## 简体中文

SwitchShelf 首个 GitHub 预发布安装包，提供原生 macOS Switch 游戏库、sphaira MTP 安装、设备内容清单、文件管理与相册截图功能。

### 系统要求与下载

- macOS 26 或更新版本，Apple Silicon（M 系列芯片）；本安装包不支持 Intel Mac。
- 下载附件 `SwitchShelf-0.3.6-arm64.dmg`。GitHub 自动生成的 Source code 压缩包是源码，不是安装包。
- 使用者无需 Apple 开发者账号，也无需安装 Xcode、Homebrew 或 libusb；所需 libusb 运行库与许可已随应用打包。
- 应用界面目前以中文为主。

### 安装与首次打开（重要）

**本版本使用 ad-hoc 本地签名，未使用 Apple Developer ID 发行签名，也未经 Apple 公证。macOS 首次打开时可能提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”，并阻止启动。**

1. 从本仓库的 GitHub Release 下载 DMG，打开后将 `SwitchShelf.app` 拖入 `Applications`（应用程序）。
2. 从“应用程序”尝试打开 SwitchShelf。如果出现上述安全提示，关闭提示后继续下一步。
3. 确认下载来源为本仓库的 Release，再打开 **系统设置 → 隐私与安全性**，向下找到与 SwitchShelf 对应的拦截提示，点击 **仍要打开**。
4. 在后续确认框选择 **打开**，并按系统要求验证身份。允许后通常可直接双击打开。

以上为 Apple 提供的针对单个应用的允许步骤，无需关闭系统整体安全检查。受单位管理的 Mac 可能由管理员限制此操作。若提示文件已损坏、会损害电脑或被检测为恶意软件，请停止运行并核对下载与校验结果，不要将这些提示视为普通的开发者验证提醒。

Apple 官方说明：[在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

### 校验下载文件

将 `SHA256SUMS` 与 DMG 下载到同一目录，在终端进入该目录后运行：

```sh
shasum -a 256 -c SHA256SUMS
```

输出对应 DMG 的 `OK` 表示文件与本次发布的校验值一致；校验值不替代 Apple 公证。

### 功能与使用说明

- 本地及已挂载 SMB/NAS 游戏库，支持网格、列表、搜索、筛选和本体 / 更新 / DLC 选择。
- sphaira MTP 串行安装与独立结果核对；安装目标以 sphaira 设备端设置为准。
- sphaira `Games` / DBI `Installed games` 已安装内容清单。
- 设备文件浏览、单文件上传 / 下载，以及相册图片浏览、预览与下载。
- 独立的 DBI FTP 只读目录探测、来源与缓存维护。

使用 USB 前请退出 OpenMTP 等其他 MTP 客户端。在 sphaira 中启用 MTP 和 `Games` 读取清单；安装时进入 **MTP Install** 并在设备端选择目标。

### 已知限制

- 这是未公证的预发布版本，尚未验证所有 Switch、sphaira、DBI 和网络存储组合。
- 传输完成与确认已安装是不同状态。sphaira 的 `Games` 可能保留缓存；刷新或重新打开 sphaira 后，可在应用中手动重新读取清单，无需再次发送文件。
- 文件名解析出的包身份为候选匹配；历史缓存不能证明设备当前安装状态。
- DBI FTP 目前仅有测试夹具与本机回环服务器验证，尚无真实 Switch FTP 会话验收。

## English

The first GitHub pre-release package of SwitchShelf, a native macOS Switch library with sphaira MTP installation, device inventory, file management, and album screenshots.

### Requirements and download

- macOS 26 or later and Apple Silicon (M-series). This package does not support Intel Macs.
- Download `SwitchShelf-0.3.6-arm64.dmg` from the release assets. GitHub's automatically generated Source code archives contain source files, not an installable app.
- Users do not need an Apple developer account, Xcode, Homebrew, or a separate libusb installation. The app bundles its libusb runtime and license.
- The application UI is currently primarily in Chinese.

### Installation and first launch (important)

**This build uses an ad-hoc local signature. It is not Developer ID signed or notarized by Apple. On first launch, macOS may block the app with a warning that the developer cannot be verified or that Apple cannot check it for malicious software.**

1. Download the DMG from this repository's GitHub Release, open it, and drag `SwitchShelf.app` into `Applications`.
2. Try opening SwitchShelf from Applications. If one of the warnings above appears, dismiss it and continue below.
3. Confirm that you downloaded the app from this repository's Release. Open **System Settings → Privacy & Security**, scroll down to the warning for SwitchShelf, and click **Open Anyway**.
4. Click **Open** in the confirmation dialog and authenticate if macOS requests it. Subsequent launches can normally use a regular double-click.

These are Apple's steps for allowing an individual app; you do not need to disable system-wide security checks. A managed Mac may restrict this action. If macOS says the file is damaged, will damage your computer, or contains malware, stop and check the download and checksum rather than treating it as a routine developer-verification warning.

Apple's instructions: [Safely open apps on your Mac](https://support.apple.com/en-us/102445).

### Verify the download

Download `SHA256SUMS` and the DMG into the same folder, open that folder in Terminal, and run:

```sh
shasum -a 256 -c SHA256SUMS
```

An `OK` result for the DMG confirms that it matches this release's checksum. A checksum does not replace Apple notarization.

### Features and usage

- Local and mounted SMB/NAS libraries with grid/list views, search, filtering, and base/update/DLC selection.
- Serial sphaira MTP installation with independent result verification; the device-side sphaira settings determine the installation destination.
- Installed-content inventories from sphaira's `Games` or DBI's `Installed games`.
- Device file browsing, single-file uploads/downloads, and album image browsing, previews, and downloads.
- A separate DBI FTP read-only directory probe, plus source and cache maintenance.

Quit other MTP clients, including OpenMTP, before using USB. Enable MTP and `Games` in sphaira for inventory reads. For installation, enter **MTP Install** and select the destination on the device.

### Known limitations

- This is an unnotarized pre-release. Not all Switch, sphaira, DBI, and network-storage combinations have been validated.
- Transfer completion and confirmed installation are separate states. sphaira's `Games` storage may remain cached; refresh or reopen sphaira, then manually read the inventory again without resending files.
- Package identities parsed from filenames are matching candidates. Historical caches do not establish the device's current installation state.
- DBI FTP validation currently covers fixtures and a local loopback server, not a real Switch FTP session.
