# SwitchShelf 界面 Demo 提示词

- 生成方式：内置 image_gen 工具（imagegen 技能）
- 页面：游戏库主界面；三版采用相同的信息架构，便于比较视觉风格。
- 说明：概念效果图，游戏、数量与设备状态为演示数据。

System blue accent, muted secondary text, 12pt custom cover corner radius, subtle selected card border, soft minimal window shadow. Compact unobtrusive toolbar. Generous 24pt page padding and consistent 20pt grid gaps. Covers sit directly on the canvas with title and metadata beneath, not bulky nested panels. The right inspector has neat compact content groups. Visually close to an excellent Apple-native library app. Absolutely no full-page colorful gradients.
